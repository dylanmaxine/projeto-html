# CONEC.JOV

## Sobre o projeto

A CONEC.JOV é uma organização sem fins lucrativos fictícia criada como projeto acadêmico para promover a inclusão social e o desenvolvimento de jovens em situação de vulnerabilidade.

O projeto consiste no desenvolvimento de uma aplicação web com o objetivo de apresentar informações sobre a organização, seus cursos, projetos e oportunidades de participação.

A aplicação também possui funcionalidades interativas desenvolvidas com JavaScript, proporcionando uma experiência mais dinâmica ao usuário.

---

## Objetivo

O objetivo do projeto é aplicar conhecimentos de desenvolvimento front-end na criação de uma interface web organizada, acessível e interativa para uma organização do terceiro setor.

Entre os principais objetivos estão:

- Apresentar a proposta da CONEC.JOV;
- Divulgar cursos e programas de capacitação;
- Permitir a pesquisa de cursos;
- Disponibilizar um formulário de inscrição;
- Armazenar os dados da inscrição no navegador;
- Organizar a aplicação utilizando uma estrutura de SPA;
- Aplicar conceitos de HTML, CSS e JavaScript.

---

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript
- Chart.js
- Git
- GitHub
- Vs code

### HTML5

Utilizado para estruturar o conteúdo da aplicação, incluindo cabeçalho, navegação, formulários, listas, títulos e demais elementos da interface.

### CSS3

Utilizado para estilização da aplicação, organização dos elementos, cores, tipografia, espaçamentos e layout.

### JavaScript

Utilizado para implementar a interatividade da aplicação, manipulação do DOM, eventos, validação de formulário, pesquisa de cursos, navegação da SPA e armazenamento de dados.

### Chart.js

Biblioteca utilizada para criar o gráfico de cursos disponível na página de Cursos.

### Git e GitHub

Utilizados para controle de versão e armazenamento remoto do projeto.

### Vs code

Utilizado para realizar a criação do site

---

## Funcionalidades

Atualmente, o projeto possui as seguintes funcionalidades:

- Navegação entre as áreas da aplicação;
- Estrutura de Single Page Application (SPA);
- Exibição dos cursos disponíveis;
- Pesquisa de cursos;
- Formulário de inscrição;
- Validação dos campos do formulário;
- Mensagens de erro e sucesso;
- Armazenamento da inscrição utilizando `localStorage`;
- Recuperação dos dados armazenados;
- Gráfico de cursos utilizando Chart.js;
- Menu de navegação;
- Interface estilizada com CSS.
